# Deployment notes — Awakening Culture Technology

Generated by `node scripts/build.mjs`. The `dist/` folder is the entire website:
static HTML, CSS, JS and images. No server runtime is required.

## Languages built
- `en` (English) — served from the site root
- `zh` (中文) — served from /zh/
- `es` (Español) — served from /es/
- `de` (Deutsch) — served from /de/
- `fr` (Français) — served from /fr/
- `ru` (Русский) — served from /ru/

## What to do before going live

1. **Inquiry form endpoint.** Open `src/config.js` and set
   `integrations.inquiryEndpoint` to a Formspree / Basin / Getform form URL or
   your own handler. Until then the form falls back to opening the visitor's
   mail client, and the amber "demo mode" banner stays visible on every page.
2. **Reserve your domain.** Set `site.url` in `src/config.js` to the final
   domain, then rebuild so canonical URLs, hreflang tags, the sitemap and
   structured data all point at the right host.
3. **Payments (optional).** Create a Stripe Payment Link and set
   `integrations.stripePaymentLink`, or set `integrations.paypalClientId`.
   Orders currently route to a quotation request instead of taking payment.
4. **Analytics (optional).** Set `integrations.gaMeasurementId` and/or
   `integrations.clarityId`. Nothing is loaded until an ID is present.
5. **Replace placeholder artwork.** Every image in `assets/img/` is a generated
   placeholder. Drop real photography in with the *same filename* — no code
   changes needed. Recommended sizes are in `docs/IMAGE-GUIDE.md`.
6. **Replace the placeholder PDFs.** The files in `assets/docs/` are minimal
   valid PDFs generated as placeholders. Swap in real datasheets.
7. **Legal review.** `terms.html`, `privacy.html` and `shipping.html` are a
   commercially reasonable starting point, not legal advice. Have them reviewed
   by counsel in China and in your target markets.
8. **Content accuracy.** Product specifications, prices and certifications are
   illustrative placeholders. Confirm every number before publishing.

## Hosting

### Netlify
```
Build command:  node scripts/build.mjs
Publish dir:    dist
```

### Vercel
```
Build command:  node scripts/build.mjs
Output dir:     dist
```

### GitHub Pages
Push `dist/` to the `gh-pages` branch, or run the build in Actions and deploy
the artifact. Add a `CNAME` file containing your domain.

### Any web host / CDN
Upload the contents of `dist/` to your web root. Language folders sit beside
`index.html`, so relative asset paths work without configuration.

## Local preview

```
node scripts/serve.mjs        # http://localhost:4173
```
